# Phase 1B 検証記録

検証日：2026-10-11。TypeScript＋Phaser 4.2.1＋Planck.js 1.4.2。

## 仕様変更

つかんでいる車の接続中のタイヤは、衝撃・持続荷重による脱落を抑止する。
衝突と負荷計測は継続し、他の車には保護を適用しない。
離した後に判定を再開する。保持中の過荷重時間は蓄積せず、外れた部品を修復しない。

## 自動検証

`pnpm test`：20件合格。Phase 1Aの14件を保持保護の新仕様に更新し、6件追加。

- 自重120秒、通常走行20回、弱衝突、強衝突20回、高所落下。
- 素早い持ち上げ、保持中の強衝突20回で接続維持、保持中の車体でボールを受け止める。
- 極端な高速操作2400ステップ、負荷パラメータ反映、持続荷重判定、停止と再開。
- 試験リセット100回、試験ボール上限と消された部品の選択解除。
- 停止中の車全体の移動・回転、接続点の一致、壁外・物体重なりの拒否。
- 車・積み木・ボール・固定坂道の共存、積み木の保持、固定坂道の保持拒否。
- JSON化した配置から100回の世界再構築：位置・接続・剛体数・ゼロ速度を復元。
- 停止だけなら戻り先維持、編集後の再生で戻り先更新、脱落した接続状態の復元。
- 保持保護が他の車に波及しない、解放直後に遅延損傷なし、新しい衝突では脱落。
- 動的剛体60個の上限、2秒の物理シミュレーション、全消去と空の状態への復元。

反復試験は同条件の繰り返し。全パラメータ・全配置の保証ではない。
物理壁の境界検査は一時的な6cm以内のソルバー侵入を許容する。
Planckは再構築時に角度を正規化するため、複数周回した角度は方向の一致で判定する。

`pnpm build`：TypeScript検査と本番ビルド合格。約1.62MB（gzip約427KB）のチャンクサイズ警告あり。

## 未検証・残る制約

- iPad Safari実機、タッチの長時間操作、子どもの操作感。
- 60剛体のブラウザ実機性能・発熱・電池消費。上限試験はNode上の物理のみ。

## 追加：タイヤが取れないモード

オンではすべての車の脱落だけを抑止し、衝突・回転・負荷計測は継続する。

遅延損傷なし、設定の復元と旧スナップショット互換、脱落済みタイヤの非修復を検証。

## 追加：タイヤの埋まりとホイールアーチ

タイヤ中心・回転ジョイントを下方向0.52mから0.44mへ移動。
車体SVGにはタイヤ上端を囲む透明なホイールアーチと縁を追加し、車の定義バージョンを2にした。
初期の床位置はタイヤ定義から計算する。接続中は既存の衝突除外で車体との重なりを許容する。

深い埋まり（0.25m・0.38m）では強い試験ボールが車体に先に当たり、脱落試験が失敗した。
接続位置0.40〜0.48mを比較し、通常荷重・走行・強衝突・保持・投擲の既存23試験を通る0.44mを採用。
脱落閾値や保持パラメータは変更していない。
型検査と本番ビルド合格。ブラウザでも強衝突で1本脱落、やりなおすで2接続に復元することを確認。
画像は `wheel-arches-preview.jpg`。当たり判定は車体の簡易矩形であり、アーチの空洞を厳密には再現しない。

## 追加：素材・背景と車種拡張の共通化

積み木・固定坂道を木目付きSVG、背景を明るい作業場に更新。
サッカーボール（黒白のパネル）と野球ボール（赤い縫い目）の2種類を用意した。
球体の柄は物理の角度で回転する。物理特性は同じ。写真のような完全な球面描画ではなく、陰影を描いた2D素材。

描画は `rendering.ts` に分離し、全種類で部品定義の外観IDを参照する。
素材URL・描画原点・寸法は `appearance.ts` に分離。物理にブラウザ画像ローダーを持ち込まない。
物体カタログから追加ボタンと種類の型を生成し、車体・タイヤ・車軸を組む `vehicleDefinition` を導入した。
パトカーや救急車はこの定義と専用素材で追加する構造。車種自体やサイレンは今回未追加。
手順は `object-authoring.md`。

自動テスト24件合格。既存の23件に、2種類のボールの坂道上の回転・種類を保った配置復元を追加。
型検査・本番ビルド合格。SVG素材合計約12.5KB（未圧縮）。既存のチャンクサイズ警告は継続。
ブラウザで木目・柄・背景の読み込み、移動、坂道での回転、全消去、再追加、7物体の配置復元を確認。
確認時点のブラウザエラー・警告ログなし。画像は `materials-workshop-preview.jpg`。
物理性能・iPad Safari実機・新素材を使った子どもの視認性評価は別途確認が必要。

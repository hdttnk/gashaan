# Phase 1A 検証記録

検証日：2026-10-11（日本時間）。Node.js v24.19.0、pnpm 11.25.0。

## 自動検証

`pnpm test`：14テスト合格。

| 試験 | 結果 |
|---|---|
| 自重・120秒のシミュレーション | タイヤ2つ接続を維持 |
| 通常走行20回 | 接続維持、車輪が回転し車体が移動 |
| 弱いボール | 脱落なし |
| 強いボール20回 | 各試験で少なくとも1つ脱落 |
| 高所落下 | 脱落、有限値を維持 |
| 通常速度の持ち上げ・投擲 | 追従誤差15cm未満、接続維持、離す時に速度の二重付与なし |
| 空中保持中のタイヤ直撃20回 | 保持を維持し、各試験で脱落 |
| 4mの速い持ち上げ | 衝突のない状態では接続維持、0.5秒後に追従誤差10cm未満 |
| 保持中の車体直撃 | ボールが戻り、車体の保持を維持 |
| 極端な目標位置変更・壁・投擲を2400ステップ | 有限値、速度上限、形状の壁への侵入6cm以内 |
| 保持と破断パラメータ変更 | 保持設定と脱落結果に反映 |
| 持続荷重による脱落 | 衝撃限界と独立した判定を確認 |
| 停止・再開 | 保持解除、停止中に時間と位置が進まない |
| 試験リセット100回・連続発射 | 剛体4つ、接続2つに復元。ボールは4つまで |

反復試験は同じ初期条件の再試験であり、20種類のランダム配置試験ではない。
形状境界検査の6cmはソルバーの一時的な重なりを許す判定値で、完全な非接触を保証するものではない。
あらゆる高速操作やパラメータの組み合わせで貫通しないことを保証する試験ではない。

`pnpm build`：型検査とVite本番ビルド合格。約1.61MBのチャンクに関するサイズ警告あり。

## ブラウザ確認

Codexの内蔵ブラウザでlocalhostを開いて確認。

- 仮図形、壁、車体、タイヤ、調整UIを描画。
- 実際のドラッグで持ち上げ・投擲イベントが発生。
- 初回の速いドラッグで持続荷重による誤脱落を発見。標準の持続荷重限界と許容時間を調整。
- 修正後の速い持ち上げ直後に2つの接続を確認。投擲後の天井衝突では脱落する。
- 空中自動保持試験（通常の保持と同じ物理処理）で、車体保持中にタイヤ直撃で脱落。
- 弱衝突後に2つの接続を確認。
- 保持力スライダーを3000Nから3100Nへ変更し表示へ反映。
- ブラウザの記録したエラー・警告ログは確認時点でなし。

証拠画像：`phase-1a-held-impact.jpg`。車体を空中で保持したまま、タイヤが外れた状態。

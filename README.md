# がしゃーん！ラボ — Prototype 0.1 / Phase 1B

自由配置・再生・保持・投擲・タイヤ脱落・配置復元を試せる最小サンドボックス。
ユーザーの実機プレイ結果を待つ段階。Phase 2には進めていない。

## 起動

Node.js 22.12以上とpnpmを使用。

```sh
pnpm install
pnpm dev
```

ブラウザで http://127.0.0.1:5173/ を開く。

このMacでは通常のPATHにNodeがないため、Codex同梱ランタイムで構築・検証した。
同じ環境で再起動する場合は以下を使える。

```sh
export PATH="/Users/hideto/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin:$PATH"
/Users/hideto/.cache/codex-runtimes/codex-primary-runtime/dependencies/bin/fallback/pnpm dev
```

```sh
pnpm test       # 物理モデルの自動試験
pnpm typecheck  # TypeScript検査
pnpm build      # 型検査と配信用ビルド
```

依存はロックファイルで固定。Phaser 4.2.1、Planck.js 1.4.2を使用する。
pnpm-workspace.yamlでesbuildだけに依存ビルドを許可している。

## 操作

- 停止中：上のボタンで車・積み木・ボール・坂道を追加。ドラッグで移動、選んで「まわす」で15度回転。左右矢印キーも使用できる。
- 車は接続中の部品をまとめて移動・回転する。外れたタイヤは単独で操作できる。
- 深い重なりやステージ外への配置は赤く表示し、離すと元の場所へ戻す。浅い接触（2.5cm以内）は許容する。
- 再生中：車・積み木・ボール・外れたタイヤをドラッグで保持。離すとその時点の速度で投げる。
- 保持している車だけは、接続中のタイヤが外れない。負荷は計測を続ける。離した後は脱落判定が再開し、過去の損傷は持ち越さない。既に外れたタイヤは修復しない。
- 「タイヤが取れない」をオンにすると、すべての車で脱落判定を抑止する。衝突・車輪の回転・負荷計測は継続。初期値はオフで、停止中・再生中のどちらでも切り替えられる。設定は配置スナップショットに含め、「やりなおす」で戻り先の設定へ復元する。
- 坂道は固定物。停止中に動かせるが、再生中には持ち上げられない。
- Space：停止／再生、R：やりなおす。追加と回転は停止中だけ。
- 「やりなおす」：最後に配置を変えて再生した直前の状態を復元し、停止する。速度・負荷・計測・イベントを初期化。
- 停止しただけなら戻り先は変わらず、再生すると速度を保って続行。配置や設定を変えたら、再生時に戻り先を更新し、全物体の速度をゼロから開始する。外れたタイヤは外れた状態を記録する。
- 「ぜんぶけす」：空のステージにして停止。戻り先も空に更新する。
- 実験・調整パネルは初期状態では閉じている。B：強い試験ボール、G：弱い試験ボール。
- 「空中で保持（試験）」：同じ有限力の保持で、1秒かけて3m持ち上げる。再度押すと離す。
- 「ボールを狙う場所」で車体直撃とタイヤ直撃を比較できる。
- タブ移動やフォーカス喪失で停止する。戻ったら「再生」を押す。
- スライダーは即時反映。「やりなおす」は戻り先に記録した設定へ復元。「軽快（標準）」で標準設定へ戻せる。
- タッチ入力経路は実装済みだが、iPad実機は未検証。ゲーム領域ではスクロール・ピンチを抑制する。

## 実装

- `src/physics.ts`：描画に依存しない物理モデル。m・kg・s、16×9の固定空間。
- `src/catalog.ts`：物体・部品・接続のデータ定義。
- `src/geometry.ts`：停止中の配置判定と形状境界。
- `src/appearance.ts`：外観IDと画像・原点・描画寸法の対応。
- `src/rendering.ts`：背景とすべての物体の共通描画。素材がない部品は仮図形へフォールバック。
- `src/assets/car-body.svg` / `car-wheel.svg`：車体とタイヤを分けた外観。塗装・窓・灯火・ゴム・ホイールの表現。部品の物理位置と角度に追従し、再構築・削除時に描画も更新する。
- `src/main.ts`：Phaser描画、Pointer Events入力、試験操作、デバッグ表示。
- `tests/physics.test.ts`：自重、走行、衝突、保持、投擲、負荷調整、停止、繰り返し試験。

車体4kg、タイヤ各0.7kgを独立した剛体として回転ジョイントで接続する。
接続中は車体とそのタイヤの衝突を無効化し、解除後は再び衝突する。
形状は車体2.2×0.36m、タイヤ半径0.32m。装飾のキャビンに当たり判定はない。
タイヤ中心は車体から下へ0.44m。以前の0.52mから上げ、ホイールアーチに少し収まる位置に変更した。
接続中は車体との重なりを許す。車の定義バージョンは2。初期の床位置はタイヤの定義から算出する。
車の外観はSVGテクスチャに更新済みだが、物理形状は引き続き簡易形状。屋根部分の衝突・つかみ判定は今後の調整対象。
接続点の緑のマーカーは実験・調整パネルを開いたときだけ表示する。

物理更新は1/120秒固定、速度10・位置6反復。Phaserの物理機能は使わない。
描画1回につき最大8ステップ。処理が追いつかないときは蓄積時間を捨て、デバッグ欄に表示する。
CCD、厚い壁、目標の移動速度上限、物体の速度上限を併用する。回転速度も30rad/sに制限する。
保持中の車体だけは回転速度を標準4rad/sに抑える。保持目標は接続中の全形状を考慮し、壁から標準0.3mの余裕を持たせる。
回転による角のめり込みと、保持で壁の内部へ引き続けることを抑える対策。
速度制限は遊びやすさと安定性のために運動エネルギーを減らす処理で、厳密なエネルギー保存は行わない。

保持はMouseJointの有限力、姿勢は上限付きのPDトルク制御。再生中の座標テレポートは行わない。
投擲ではポインター速度を重ねず、保持中に得た速度をそのまま使う。

ジョイント反力×物理刻み時間を衝撃指標とし、持続荷重と別々に判定する。
これはソルバー由来の指標であり、材料の正確な破壊モデルではない。接触インパルスも別途表示する。
世界の変更は物理ステップの後。脱落イベントは接続ごとに一度だけ発生する。
試験ボールは最大4個、重力ゼロ。通常のボールは重力あり。動的剛体60・接続定義20・固定坂道10を上限にしている。

配置復元はバージョン付きのJSON化可能なスナップショットから世界を再構築する。
物体ID・定義バージョン・部品の位置と角度・接続状態・設定を記録し、ソルバーのキャッシュは保存しない。
保存UIは未実装。復元後の物理は同じ配置から再計算するため、ブラウザをまたぐ完全一致リプレイは保証しない。

## 既知の制約

- 保持中の脱落抑止は遊びやすさのためのルールであり、厳密な材料力学モデルではない。
- 非常に速い投擲で天井や壁にぶつかると脱落する。衝突のない速い持ち上げでは接続を保つ試験を用意した。
- 有限力なので、壁の向こうへポインターを動かすと物体との距離が生じる。
- 全パラメータの組み合わせの安定性は保証しない。弱い接続設定は自重でも外れる。
- バンドル約1.61MB（gzip約423KB）に対するVite警告がある。初期試作では分割を優先していない。
- セット、音、保存UI、部品自体の破壊、ズーム、リアル／デフォルメモードは未実装。
- 機種別性能測定、iPad Safari、子どもの操作性評価は未実施。

検証記録は `docs/phase-1b-verification.md`。Phase 1Aの過去の記録は `docs/verification.md` に保存している。
外観は木製の積み木・坂道、柄のあるサッカーボール・野球ボール、明るい作業場へ更新。
2種類のボールの物理特性は同じ。車種や素材の追加手順は `docs/object-authoring.md`。
次の段階は、配置・回転・戻り先の分かりやすさと、複数物体を使った操作感の実機評価後に判断する。


## 追加オブジェクト（2026-10-11）

停止中のパレットから、パトカー・救急車・消防車・三角積み木・長方形積み木を追加できる。
各車は専用の車体外観と2つの回転タイヤを持つ。消防車・救急車はサイズと質量も異なる。
保持中のタイヤ保護と「タイヤが取れない」モードは全車共通。強い落下では離した車のタイヤが外れる。
三角は当たり判定も三角形。長方形とともに停止中の配置・回転、再生中の保持、やりなおしに対応する。
サイレン・点滅・はしごや扉の可動は今回の範囲に含めない。
検証記録：`docs/object-additions-verification.md`。

## モバイル向け画面（横画面専用）

ページ全体をゲームにし、壁の内側に操作UIを重ねた。Safariの表示領域を使う方式で、ブラウザのアドレスバーを強制的に消すものではない。

- 「＋ もの」でパレットを開くと停止。選択して追加すると閉じる。
- 再生・やりなおしは上部。停止中に選択すると左下に回転ボタン。
- 「タイヤが取れない」と「ぜんぶけす」はパレット内。
- 右下の歯車で開発者パネル。開閉時は停止し、内部の再生・試験ボタンで計測できる。
- 縦向きは操作不可。「横向きにしてね」の案内を表示。PCではウィンドウを横長にする。
- 横画面の高さを8.6mに保ち、幅を画面比率に合わせる。物体の形状・質量・接続は変えない。
- 画面サイズ変更時は停止し、接続された部品をまとまりで移動して新しい壁内へ収める。やりなおすの配置も同じ規則で移動する。重なりが生じた場合は修正するまで再生しない。
- 配置データにステージ寸法を記録。過去の寸法なしデータは16×8.6mで復元。

### 個別削除と取り消し

停止中に物体をタップして選び、画面左下の「🗑 けす」で削除できる。
接続中の車体とタイヤはまとめて削除し、外れたタイヤは単独で削除する。
「↶ けすのをもどす」で直近20回の削除を新しい順に取り消せる。
別の物体の追加・移動や設定変更は巻き戻さない。戻す場所が重なったり個数上限を超える場合は案内を表示し、履歴を保持する。
再生・やりなおす・ぜんぶけす・ステージ寸法の変更で削除履歴を破棄する。
削除も配置編集として扱い、次の再生時に「やりなおす」の基準へ反映する。
